# Polices du livrable de relecture

`ebgaramond-*.ttf` — EB Garamond, distribuée sous SIL Open Font License 1.1
(https://fonts.google.com/specimen/EB+Garamond). Les fichiers sont versionnés
ici pour que `npm run copy-review` régénère le PDF à l'identique, hors ligne et
sans dépendre des polices installées sur la machine.

Marcellus (titres) est repris de `public/fonts/marcellus.woff2`, la police
d'affichage du site.
